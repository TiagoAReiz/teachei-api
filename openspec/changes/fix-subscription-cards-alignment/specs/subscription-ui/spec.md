# Capability: Subscription UI

## MODIFIED Requirements

### Requirement: Subscription Plan Cards Layout
The subscription page SHALL display plan cards in a properly aligned grid.

#### Scenario: Cards display with recommended highlight
- **WHEN** the subscription page loads
- **THEN** all three plan cards MUST be visible and fully rendered
- **AND** the "Recomendado" badge on the Trimestral plan MUST be fully visible
- **AND** the elevated middle card MUST not cause visual clipping
- **AND** cards MUST align at the bottom of the grid row
